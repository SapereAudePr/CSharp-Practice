# CSharp-Practice

A personal collection of C# practice projects and exercises, covering everything from language fundamentals to OOP, generics, delegates/events, LINQ, Entity Framework Core, and small standalone apps. Each folder is a self-contained project or exercise built while learning a specific concept.

## Contents

### Fundamentals
- **Arrays** — array basics and manipulation
- **Loops / LoopsPractice** — `for`, `while`, `foreach` exercises
- **Methods** — method declarations, parameters, return types
- **StrucsPractice** — working with structs
- **TuplePractice** — tuples in C#
- **EnumPractice** — enums
- **DictionaryPractice / LastTutorialDictionaryPractice** — `Dictionary<TKey,TValue>` usage
- **ListsPractice** — `List<T>` operations
- **Conditional-Based Calculator** — conditionals and branching logic
- **CalculatingAverageTemperature** — basic data processing exercise
- **GuessNumberInfiniteLoop** — loop control with a number-guessing game
- **OldStyle / Program / Program2 / Practice259 / Practice2385App / TutorialExercise21459** — early tutorial exercises and scratch programs

### Object-Oriented Programming
- **ClassPractice / ClassesOOP** — classes, fields, properties, constructors
- **InheritancePractice / InheritancePractice2** — inheritance and polymorphism
- **InterfacePractice / InterfacePractice1295** — interfaces
- **InterfaceSegregationPrincipleApp** — SOLID principles (ISP)
- **InterfaceDI-Practice** — interfaces with dependency injection
- **PaymentServicePractice** — service-oriented OOP design example
- **HospitalDemoApp** — larger OOP domain-modeling example

### Delegates, Events & Generics
- **ActionDelegatePracticeApp / DelegatesPractice** — `Action`, `Func`, and custom delegates
- **EventsPracticeApp / EventsPractice239App / EventArgsPracticeApp** — events and `EventArgs`
- **GenericsExample / GenericsAdvanced569App / GenericsAdvancedPractice453App** — generic types and methods
- **GenericsAndDelegatesApp** — combining generics with delegates

### LINQ & Async
- **LINQPractice1249App** — LINQ queries
- **TaskPracticeApp** — `Task` and asynchronous programming
- **Threads** — multithreading basics

### Files, Text & Documents
- **FileManagementPractice** — reading/writing files
- **RegexPracticeApp / RegexPracticalApp** — regular expressions
- **PDFDemoApp** — generating/working with PDFs

### Databases (EF Core / SQL)
- **DatabaseFirstPracticeApp** — database-first EF Core workflow
- **EFCorePracticeDemo / EFDemoApp / EFDemo2App** — Entity Framework Core CRUD and modeling
- **NorthWindSQLPracticeApp** — queries against the Northwind sample database
- **TestingSQLApp** — SQL testing/practice

### Testing
- **UnitTestPracticeApp** — unit testing practice

### Small Apps & Projects
- **WeatherApp / WeatherStationSimulator** — weather data apps
- **SimpleToDoDemoApp** — a basic to-do list app
- **QuizProject** — a quiz application
- **TextAdventureGame** — a console-based text adventure
- **StockPriceCourseExerciseApp** — stock price tracking exercise
- **WebDemo** — a basic web app
- **WpfPracticeApp / WpfPractice238** — WPF desktop UI practice

## Tech Stack
- **Language:** C# (98%), with some T-SQL (2%)
- **Framework:** .NET

Some projects (e.g. those under **Databases**) require a local SQL Server instance or connection string configuration — check the project's `appsettings.json` or `Program.cs` for connection details before running.

## Purpose

This repository is a personal practice log rather than a single application — each folder represents a step in learning C# and .NET, from core syntax through OOP design, generics, LINQ, and data access with EF Core.
